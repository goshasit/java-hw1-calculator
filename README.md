\# Java Calculator



Консольный калькулятор на Java.



Поддерживаемые операции:



`+` — сложение

`-` — вычитание

`\` — умножение

`/` — деление

`C` — сброс и ввод нового первого числа

`S` — завершение работы



Также предусмотрена обработка ошибок:



\* деление на ноль;

\* неподдерживаемая операция.
